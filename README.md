# typing-quest

## ローカル起動

```sh
docker compose up -d
```

http://localhost:8080 を開きます。

## ローマ字入力の確認

日本語モードでは `shi/si`、`tsu/tu`、`chi/ti`、`fu/hu`、拗音、
小文字の `x/l`、促音、子音前・語末の「ん」の別表記を受け付けます。
お題のローマ字表示は、入力した別表記に合わせて切り替わります。
英語モードではローマ字の別表記を適用しません。

時間制限なしで確認する場合は、リポジトリのルートで次を実行します。

```sh
python3 -m http.server 8081 --bind 127.0.0.1
```

http://localhost:8081/tests/romaji.html でお題を選び、入力してください。
この確認ページはゲーム本体と同じ判定・入力・進捗表示処理を使います。
戦闘のタイマーやダメージ処理は実行しません。

Node.js が利用できる環境では、依存パッケージなしで回帰テストを実行できます。

```sh
node tests/romaji.test.cjs
```
